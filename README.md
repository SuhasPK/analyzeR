# analyzeR

A shiny web app which has all the basic functionality of a data workflow, from uploading to cleaning, analyzing, visualizing, and finally removing datasets.

Each functionality is based on the work that is specified to do. These functionality include:

1.  **readR**: The user can upload the dataset of desired format which includes .csv, .xlsx, .tsv, and .txt. Furthermore, an information box having the key info about the dataset will be displayed. And a preview of the dataset will also be displayed.
